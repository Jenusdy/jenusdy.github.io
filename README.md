# Jenusdy's Portfolio & Blog (`jenusdy.github.io`)

Personal portfolio and technical blog website for Fawcet Jenusdy Makay, built with [Gatsby v5](https://www.gatsbyjs.com/) and [`gatsby-theme-portfolio-minimal`](https://github.com/konstantinmuenster/gatsby-theme-portfolio-minimal).

- **Live URL:** [https://jenusdy.github.io/](https://jenusdy.github.io/)
- **Comprehensive Developer Guide:** See [AGENTS.md](file:///home/jenusdy/Projects/jenusdy.github.io/AGENTS.md) for full project architecture, directory layout, content schemas, and operational runbook.

---

## Quick Start

### 1. Prerequisites
- Node.js >= 18 (e.g. Node 20 LTS)
- npm (or Docker)

### 2. Local Development

```bash
# Install dependencies
npm install

# Start development server with live reload
npm run develop
```

Open [http://localhost:8000](http://localhost:8000) in your browser.
GraphiQL explorer is available at [http://localhost:8000/___graphql](http://localhost:8000/___graphql).

### 3. Docker Alternative

```bash
# Start development container
docker compose up -d gatsby-dev

# Stop container
docker compose down
```

### 4. Build & Production Preview

```bash
npm run build
npm run serve
```
